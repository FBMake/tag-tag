# tag-tag

Petit site pour créer et imprimer des étiquettes sur une imprimante à ruban branchée en USB (testé avec une Brother P-touch D610BT, ruban 18 mm Laminated White).

L'impression passe par la boîte d'impression du navigateur et le pilote de l'imprimante. Le site est statique (HTML, CSS, JavaScript) et hébergé sur GitHub Pages.

## Lancer en local

Ouvrir `index.html` dans le navigateur, ou :

```
python3 -m http.server
```
